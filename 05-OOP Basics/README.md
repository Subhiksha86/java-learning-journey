# OOP Basics

This folder contains my Java programs for learning the basic concepts of Object-Oriented Programming (OOP).

## Topics Covered

### Class and Object

- Creating a class
- Creating an object
- Using objects to access methods
- Passing values to methods

### Methods

- Creating methods
- Methods with parameters
- Methods with return values
- `void` methods
- Calling methods using objects

### Method Overloading

- Using the same method name with different parameters
- Overloading methods with different numbers of parameters
- Overloading methods with different parameter types

## What I Learned

I learned how classes and objects are used in Java and how methods help organize functionality inside a program.

I also learned about method overloading, where multiple methods can have the same name as long as their parameter lists are different.
